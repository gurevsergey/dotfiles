# tmux — руководство

Руководство по tmux в той конфигурации, что установлена в этом репозитории (конфиг craftzdog с правками под Linux). Где что лежит и чем конфиг отличается от оригинала — в [Neovim и tmux](../README.md#neovim-and-tmux). Редактор — в [Neovim — руководство](neovim.md).

> [!IMPORTANT]
> **Префикс — `Ctrl+T`**
> Почти каждая команда tmux — это префикс, затем клавиша. Запись `prefix c` означает: нажать `Ctrl+T`, отпустить, нажать `c`. Стандартный `Ctrl+B` в этой конфигурации отключён.

## 1. Зачем это нужно

tmux — мультиплексор терминала. Он даёт три вещи:

1. **Сеанс живёт отдельно от окна терминала.** Закрыли kitty, оборвался SSH — программы внутри tmux продолжают работать, к ним можно подключиться снова.
2. **Несколько терминалов в одном окне.** Окна (как вкладки) и панели (деление окна на части).
3. **Одинаковая среда на любой машине.** На сервере по SSH то же управление, что локально.

### Из чего состоит

| Понятие | Что это | Аналогия |
|---|---|---|
| Сервер | фоновый процесс, держит все сеансы | — |
| Сеанс (session) | набор окон под одну задачу или проект | рабочий стол |
| Окно (window) | один экран внутри сеанса | вкладка |
| Панель (pane) | часть окна со своим терминалом | плитка |
| Клиент | терминал, подключённый к сеансу | монитор |

Практическое правило: **один проект — один сеанс**, внутри окна по видам работы (редактор, сервер, логи), панели — для того, что нужно видеть одновременно.

## 2. Быстрый старт

```sh
tmux new -s lab          # создать сеанс с именем lab
```

Дальше внутри:

1. `prefix |` — разделить окно на две панели по вертикали.
2. `prefix h` / `prefix l` — перейти в левую / правую панель.
3. `prefix c` — открыть новое окно; `prefix 1`, `prefix 2` — переключаться между окнами.
4. `prefix d` — отключиться. Сеанс продолжает работать.

```sh
tmux ls                  # что запущено
tmux attach -t lab       # вернуться
```

## 3. Сеансы

### Из оболочки

| Команда | Действие |
|---|---|
| `tmux` | новый сеанс без имени |
| `tmux new -s <имя>` | новый сеанс с именем |
| `tmux new -s <имя> -c <каталог>` | новый сеанс в заданном каталоге |
| `tmux new -A -s <имя>` | подключиться к сеансу, а если его нет — создать |
| `tmux ls` | список сеансов |
| `tmux attach -t <имя>` | подключиться (`tmux a` — к последнему) |
| `tmux attach -d -t <имя>` | подключиться и отключить остальных клиентов |
| `tmux kill-session -t <имя>` | завершить сеанс |
| `tmux kill-server` | завершить всё |

### Изнутри

| Клавиши | Действие |
|---|---|
| `prefix d` | отключиться (detach) |
| `prefix s` | дерево сеансов и окон: стрелки или `j`/`k`, `Enter` — перейти, `x` — закрыть |
| `prefix $` | переименовать сеанс |
| `prefix (` / `prefix )` | предыдущий / следующий сеанс |
| `prefix L` | последний сеанс — занято под изменение размера панели, пользуйтесь `prefix s` |

## 4. Окна

| Клавиши | Действие |
|---|---|
| `prefix c` | новое окно в каталоге текущей панели |
| `prefix ,` | переименовать окно |
| `prefix n` / `prefix p` | следующее / предыдущее окно |
| `prefix 0`…`9` | окно по номеру |
| `prefix w` | список всех окон во всех сеансах |
| `prefix &` | закрыть окно (с подтверждением) |
| `prefix <` / `prefix >` | передвинуть окно влево / вправо |
| `Ctrl+Shift+←` / `Ctrl+Shift+→` | то же без префикса |
| `prefix .` | перенести окно на заданный номер |
| `prefix f` | найти окно по тексту |

Окна перенумеровываются автоматически при закрытии (`renumber-windows on`), «дыр» в номерах не остаётся.

## 5. Панели

### Создание и закрытие

| Клавиши | Действие |
|---|---|
| `prefix \|` или `prefix %` | разделить по вертикали (панель справа), ширины выравниваются |
| `prefix -` или `prefix "` | разделить по горизонтали (панель снизу), высоты выравниваются |
| `prefix \` | вертикальная панель на всю высоту окна |
| `prefix _` | горизонтальная панель на всю ширину окна |
| `prefix x` | закрыть панель (с подтверждением) |
| `prefix e` | закрыть **все панели, кроме текущей** — без подтверждения |
| `prefix !` | вынести панель в отдельное окно |

Новая панель открывается в том же каталоге, что и текущая.

### Переход и размер

| Клавиши | Действие |
|---|---|
| `prefix h` `j` `k` `l` | перейти влево / вниз / вверх / вправо |
| `prefix ;` | предыдущая активная панель |
| `prefix q` | показать номера панелей; нажать цифру — перейти |
| `prefix H` `J` `K` `L` | изменить размер на 5 ячеек в соответствующую сторону |
| `prefix z` | развернуть панель на всё окно и обратно (zoom) |
| `prefix Space` | перебор готовых раскладок |
| `prefix {` / `prefix }` | поменять панель местами с предыдущей / следующей |
| `prefix Ctrl+O` | провернуть панели по кругу |

> [!NOTE]
> **Повтор без префикса не работает**
> В конфиге `repeat-time 0`: для каждого шага изменения размера префикс нужно нажимать заново. Зато после `prefix` + стрелка tmux не перехватывает следующую клавишу.

## 6. Режим копирования

Режим копирования — это прокрутка истории и выделение текста. Управление в стиле vi (`mode-keys vi`). История — около двух миллионов строк на панель.

| Клавиши | Действие |
|---|---|
| `prefix [` | войти в режим копирования |
| `q` или `Esc` | выйти |
| `h` `j` `k` `l`, `w`, `b`, `0`, `$` | перемещение, как в vim |
| `Ctrl+U` / `Ctrl+D` | полэкрана вверх / вниз |
| `g` / `G` | начало / конец истории |
| `/` и `?` | поиск вперёд / назад; `n` / `N` — следующее совпадение |
| `Space` | начать выделение |
| `V` | выделять строками |
| `Ctrl+V`, затем `Space` | прямоугольное выделение |
| `y` | скопировать **в системный буфер** (`wl-copy`) и выйти |
| `Enter` | скопировать во внутренний буфер tmux и выйти |
| `prefix ]` | вставить из буфера tmux |
| `prefix =` | выбрать из прежних буферов |

Типовой сценарий — достать строку из вывода команды: `prefix [`, `?` и текст для поиска, `Enter`, `V`, `y`. Дальше вставлять обычным `Ctrl+Shift+V` в kitty.

Мышь в tmux выключена. Чтобы выделить текст мышью средствами kitty, в tmux достаточно обычного выделения — оно не перехватывается.

## 7. Инструменты конфигурации

### lazygit

`prefix g` открывает lazygit во всплывающем окне на 90 % экрана в каталоге текущей панели. `q` закрывает. Нужен пакет `lazygit`.

### Claude Code во всплывающем окне (tmux-claude-hatch)

| Клавиши | Действие |
|---|---|
| `prefix y` | запустить Claude Code для текущего каталога во всплывающем окне или вернуться в уже запущенный |
| `prefix d` | закрыть всплывающее окно; сеанс Claude продолжает работать |
| `prefix u` | список всех запущенных агентов с состоянием (`working` / `waiting` / `idle`) и предпросмотром |

В списке: `j` / `k` — вверх и вниз, `Enter` — перейти, `x` — завершить агента, `i` или `a` — перейти к вводу фильтра, `Esc` — назад к навигации, `q` — закрыть.

Каждый агент живёт в собственном вложенном сеансе tmux, поэтому закрытие окна его не прерывает. Когда агент закончил ход или ждёт ответа, окно, из которого он запущен, подсвечивается в строке состояния пурпурным. Чтобы это работало, Claude Code должен подавать звонок терминала — настройка описана в README плагина (`~/.config/tmux/plugins/tmux-claude-hatch/README.md`), по умолчанию не включена.

Плагину нужны `fzf` и `jq`.

### Прочее

| Клавиши | Действие |
|---|---|
| `prefix o` | открыть каталог панели в файловом менеджере (`xdg-open`) |
| `prefix r` | перечитать конфиг; внизу появится «Reloaded!» |
| `prefix :` | командная строка tmux |
| `prefix ?` | все действующие привязки клавиш |
| `prefix t` | часы на всю панель |

## 8. Строка состояния

Слева направо:

| Сегмент | Что показывает |
|---|---|
| `сеанс:окно.панель` | где вы сейчас, например `lab:2.1` |
| имя пользователя | результат `whoami` |
| окна (по центру) | номер и имя каталога активной панели; текущее окно выделено синим, остальные жёлтым, окно со звонком — пурпурным |
| имя хоста (справа) | полезно, чтобы не перепутать локальный tmux и tmux на сервере |

Заголовок окна kitty следует за заголовком активной панели (`set-titles on`).

## 9. Рабочие приёмы

### Проект в одном сеансе

```sh
cd ~/Projects/personal/mtcap
tmux new -A -s mtcap
```

Окно 1 — `nvim`, окно 2 — сборка и запуск (`prefix |` для логов рядом), git — через `prefix g`. Вечером `prefix d`, утром та же команда возвращает всё как было.

### Долгая команда на сервере

```sh
ssh host
tmux new -A -s work
# запустить обновление, копирование, захват трафика
# prefix d — и можно закрывать ноутбук
```

После обрыва связи: `ssh host`, затем `tmux a`.

> [!WARNING]
> **tmux внутри tmux**
> Если локально вы уже в tmux и на сервере запускаете ещё один, префикс `Ctrl+T` перехватывает **внешний** tmux. Чтобы отправить префикс внутреннему, его нужно нажать дважды — но для этого требуется привязка `bind t send-prefix`, которой в конфиге нет (она закомментирована). Проще для работы на серверах открывать отдельное окно kitty без локального tmux либо добавить привязку в `~/.config/tmux/tmux-private.conf`.

### Одна команда во все панели

```
prefix :   setw synchronize-panes on
```

Всё, что вы печатаете, уходит во все панели окна — удобно для одинаковых действий на нескольких серверах. Выключить: та же команда с `off`.

### Сохранить вывод панели в файл

```
prefix :   capture-pane -S - ; save-buffer ~/pane.log
```

`-S -` берёт всю историю, а не только видимую часть.

## 10. Настройка под себя

Свои правки кладите в `~/.config/tmux/tmux-private.conf` — он подключается последним, если существует, и не затрагивается при обновлении основного конфига.

```tmux
# пример: включить мышь и отправку префикса во вложенный tmux
set -g mouse on
bind t send-prefix
```

После правки — `prefix r`.

| Файл | За что отвечает |
|---|---|
| `tmux.conf` | префикс, базовые опции, список плагинов, порядок подключения |
| `bindings.conf` | собственные привязки клавиш |
| `theme.conf` | цвета номеров панелей, часов, всплывающих окон |
| `statusline.conf` | строка состояния |
| `utility.conf` | lazygit и настройки claude-hatch |
| `linux.conf` | truecolor, undercurl, буфер обмена Wayland |

Плагины перечислены в `tmux.conf` строками `set -g @plugin`. Установка новых: `prefix I`, обновление: `prefix U`, удаление лишних: `prefix Alt+U`.

## 11. Диагностика

| Симптом | Причина и решение |
|---|---|
| Вместо скруглённых краёв строки состояния квадраты | в терминале не Nerd Font; в kitty должен быть `JetBrainsMono Nerd Font` |
| Цвета в nvim тусклые или полосатые | проверить `tmux info \| grep -E 'RGB\|Tc'`; за truecolor отвечает `linux.conf` |
| `y` в режиме копирования не кладёт текст в буфер | нет `wl-copy` (пакет `wl-clipboard`) или сеанс запущен не из Wayland |
| `Ctrl+T` в fish перестал вставлять файл через fzf | его забрал префикс tmux; вне tmux работает как раньше |
| `prefix g` ничего не открывает | не установлен `lazygit` |
| `prefix u` показывает пустой список или ошибку | не установлен `jq` |
| После правки конфига ничего не изменилось | `prefix r`; часть опций применяется только к новым сеансам — `tmux kill-server` и запуск заново |
| Нужно понять, что сейчас привязано к клавише | `prefix ?` или `tmux list-keys \| grep <клавиша>` |
